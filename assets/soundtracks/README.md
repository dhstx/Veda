# Soundtrack assets.

`demo-void/` contains the six original synthetic demo stems. Its WAVs are intentionally tracked in Git.

Put your own experiments in `private/` or another folder outside the repository. `private/` and common audio formats are ignored so the first GitHub push does not accidentally include your production music. The app loads local folders through **Load folder**.

Read `docs/SOUNDTRACK_AUTHORING.md` before replacing stems. All stems must have the same authored loop range and match the manifest exactly.
